# RoboDojo integration

This package connects the simulator, π05 policy service and GPT controller.

Use the repository-level entrypoints:

- [Installation](../../docs/INSTALLATION.md): external dependencies and assets.
- [Evaluation](../../docs/EVALUATION.md): final and baseline evaluation.
- [Configuration](../../docs/CONFIGURATION.md): collection, annotation, data preparation and training.
- [Account pool](ACCOUNT_POOL.md): managed authentication and concurrency.

Run commands from the repository root. Configure deployment paths and hardware in
`configs/deployment.local.json`; keep credentials and experiment output outside the repository.
