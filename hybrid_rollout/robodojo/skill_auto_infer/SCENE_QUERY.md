# Scene-query permissions

Scene-query tools expose simulator information and require explicit permission from the selected recipe. Evaluation disables privileged scene queries.

When enabled for collection, the controller enforces query budgets, decision identity and object-role binding. Query responses and identity images are archived with the episode. They must not be treated as ordinary camera observations in comparisons with nonprivileged evaluation.

Changing query permissions requires a new experiment name and a fresh episode session. See [configuration](../../../docs/CONFIGURATION.md).
