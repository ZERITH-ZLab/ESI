# GPT–π05 controller

The controller supports automatic policy inference and GPT subtask feedforward.
Select the route through the collection or evaluation recipe; use the repository-level launch scripts described in the [workflow guide](../../../docs/CONFIGURATION.md).

`SKILL.md`, the gate prompts and `context/` define the model-visible tools and decision contract. Runtime inputs, effective prompts, decisions and execution receipts are archived per episode.

See [feedforward inputs](FEEDFORWARD.md), [motion tools](RECOVERY_TOOLS.md) and [scene-query permissions](SCENE_QUERY.md).
