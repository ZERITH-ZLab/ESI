原视频帧 0 为初始观测；帧 k 是第 k 步动作执行后的状态。正常播放时显示产生本帧的决策（start < k ≤ end），初始帧预览首轮决策。点击列表、时间带或决策按钮时，跳到 start 对应的下发前观测，侧栏锁定所选决策；播放后恢复跟随。零步事件没有独立视频帧，单独列出并允许选择，不添加停顿。
指令读取 history.json 的 conditioning，意图判断读取 assessment。null 与旧路线缺少 conditioning 分开显示。没有离线标注时不推断子任务成功／失败。视频显示模拟器时间，不包含 GPT 等待耗时。跨实验保留同 layout / 重复选择，但不把相同时间强行解释为相同任务进度。
